# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Reporting Bugs and Suggesting Improvements

Open an issue in this repository. Describe the problem or suggestion clearly. For bugs, include the steps to reproduce the problem, the inputs used, and the expected and actual results. Do not include passwords or other private information.

## Submitting Changes

1. Fork this repository and clone your fork.
2. Create a new branch for your change.
3. Make your changes and verify that the calculator works correctly.
4. Commit your changes with a clear commit message.
5. Push the branch to your fork.
6. Open a pull request describing your changes and linking any related issue.

## Checking Your Changes

For calculator changes, check the calculation with known inputs. For example, a principal of 1000, an annual interest rate of 5%, and a period of 2 years should produce simple interest of 100.

For documentation changes, check spelling, formatting, and instructions.

## Community Standards

Please read and follow the CODE_OF_CONDUCT file when participating in this project. Be respectful and give constructive feedback.
