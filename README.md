# Simple Interest Calculator

A Bash calculator that computes simple interest using the principal amount, annual interest rate, and time period entered by the user.

## Inputs

- **Principal (P):** The initial amount invested or borrowed.
- **Annual interest rate (R):** The yearly interest rate as a percentage.
- **Time (T):** The investment or loan period in years.

## Formula

```text
Simple Interest = (Principal * Annual Interest Rate * Time) / 100
```

## Example

For a principal of 1000, an annual interest rate of 5%, and a period of 2 years:

```text
Simple Interest = (1000 * 5 * 2) / 100 = 100
```

The simple interest is 100. The total amount including the principal is 1100.

## How to Run

With Bash installed, open a terminal in the repository directory and run:

```bash
bash simple-interest.sh
```

Enter the principal, annual interest rate, and time period when prompted. The script displays the calculated simple interest.
